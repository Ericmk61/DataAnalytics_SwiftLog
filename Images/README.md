# Images

This folder contains supporting visual evidence used in the SwiftLog Logistics Business Intelligence project.

## Files

- `Executive_Dashboard.png`  
  Screenshot of the main executive Power BI dashboard.

- `Data_Model_View.png`  
  Screenshot of the Power BI data model showing the main tables and relationships.

- `Power_Query_Cleaning.png`  
  Screenshot showing representative Power Query cleaning and transformation steps.

- `DAX_Measures.png`  
  Screenshot showing custom DAX measures used in the report.

- `Dashboard_Montage.png`  
  Combined visual overview of selected dashboard pages for documentation and portfolio presentation.

These images support the project documentation, GitHub portfolio, and executive presentation without duplicating the full dashboard screenshots PDF.

# Dashboard

This folder contains the completed Power BI report for the SwiftLog Logistics analytics project.

## File

- `SwiftLog_Analytics.pbix` — interactive Power BI dashboard containing the completed data model, DAX measures, analytical pages, drill-through, tooltip, bookmarks, synchronized slicers, navigation, and mobile layouts.

## Main Report Pages

- Executive Dashboard
- Executive Trends
- Customer Analytics
- Inventory & Warehouse Analytics
- Shipment & Delivery Analytics
- Product & Supplier Analytics

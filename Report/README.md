# Reports

This folder contains the formal reporting deliverables for the SwiftLog Logistics Power BI project.

## Files

- `Executive_BI_Report.pdf`  
  A 3–5 page executive report summarizing the major KPIs, findings, business implications, limitations, and recommendations for SwiftLog leadership.

- `Dashboard_Screenshots.pdf`  
  A compiled PDF containing clean screenshots of the completed Power BI report pages and supporting visuals.

- `SwiftLog_Technical_Project_Documentation.pdf`  
  Detailed project documentation covering data preparation, data quality, Power Query transformations, data modeling, calculated fields, DAX measures, dashboard development, business analysis, limitations, and recommendations.

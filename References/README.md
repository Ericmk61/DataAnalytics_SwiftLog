# References

This folder contains the primary reference materials used to guide the SwiftLog Logistics Business Intelligence project.

## Files

- `AnalystLab_Africa_Week5_Assignment.pdf`  
  Official AnalystLab Africa Week 5 assignment brief used to guide the project requirements, deliverables, and assessment criteria.

- `SwiftLog_Data_Dictionary.xlsx`  
  Source data dictionary provided for the SwiftLog datasets.

- `Calculated_Fields_Data_Dictionary.csv`  
  Documentation for additional calculated and business fields created during the Power BI project.

- `References.md`  
  Summary of the key project reference materials and supporting documentation used during the analysis.
